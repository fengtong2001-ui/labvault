## 用户报告的两个问题

### 1. 仪表盘/项目管理「标签比例和大小完全失调」 ✅ 已修复

**根因**(一行 CSS 级别的架构问题,影响所有页面):

- `App.js` 的主内容区是 `display:flex; flex-direction:column`
- 而每个页面根节点都用了 `maxWidth:1200 + mx:'auto'`
- CSS 规范:flex 列布局中,交叉轴 auto margin 会**取消 stretch**,元素收缩为
  内容固有宽度(实测 565px)再居中 → 整页内容被压缩,快捷操作文字一字一行竖排

**修复**:主内容区改回普通 block 流(`App.js`)。仪表盘/项目管理布局全部恢复正常。

### 2. 数据/统计/图表三功能割裂 → GraphPad 式深度整合 ✅ 第一阶段完成

GraphPad Prism 的核心是「数据表 → 一键分析 → 结果/图表挂在同一数据集下」。
本轮打通的闭环:

```
数据表格页 → [以此数据运行统计] → /statistics?dataset=2
                ├─ 自动识别列类型(分类列/数值列)
                ├─ 按分组自动填充 组1/组2(三组以上自动预填 ANOVA)
                └─ 页面显示「数据来源」标签
数据表格页 → [生成分析图表]    → /charts?dataset=2
                ├─ 真实数据构建 series(柱状图 = 分组均值±SD,出版级样式)
                ├─ 数据来源标签(真实数据集 / 演示数据,诚实标注)
                └─ 数据集就绪自动生成,无需再点
```

**顺带修掉的历史缺陷**:
- ChartBuilder 的演示数据参数形状与后端 schema 不匹配(bar 用 `categories/values`,
  后端要 `series/x/y`)→ 该页面此前从未真正通过后端出图
- 后端缺失 `PUT /api/datasets/<id>` 路由(数据表格的「保存表格」对已存数据集一直
  是坏的)→ 新增 `db.update_dataset()` + PUT 路由

**改动文件**:`App.js`、`DataTable.js`、`Statistics.js`、`ChartBuilder.js`、
`utils/datasetStats.js`(新)、`backend/db.py`、`backend/server.py`

**验证**:浏览器端到端 —— 选择 QA 数据集 → 一键统计(UI 渲染真实 t 检验结果
t=-9.466, df=14, p<0.0001 ***)→ 一键图表(真实均值±SD 柱状图)。
