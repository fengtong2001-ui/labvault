# LabVault 更新公告 2026-11-18(第 12 轮 · 工作簿条目导出 JSON)

## 新增

### 工作簿条目一键导出 JSON(可复现性)

工作簿面板的分析与图表条目各新增 ⬇ 按钮:

- **分析条目** → `labvault-analysis-<id>.json`:`{_export, id, type, title,
  params, result, dataset_id, project_id, created_at}` —— 参数与结果齐全,
  离线即可复现该次检验
- **图表条目** → `labvault-chart-<id>.json`:`{_export, id, chart_type, title,
  plotly, dataset_id, created_at}` —— 完整 Plotly 图规格,任何支持 Plotly 的
  工具都能重绘

## 验证

- 载荷契约:以真实 API 数据(3 条分析 + 3 张图)按 handler 同构逻辑构造并校验,
  结构完整 ✓
- 链路:点击 ⬇ 触发浏览器下载授权弹窗(浏览器仅在收到下载请求时弹出)——
  导出链路启动已证实;浏览器侧实际保存需在 Ego 浏览器允许站点下载权限
