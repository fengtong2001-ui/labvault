# LabVault 更新公告 2026-11-18(第 16 轮 · 摘要 CSV + 结果 JSON 导出)

## 新增

### 1. 工作簿分析条目导出 CSV

分析条目新增 📊CSV 按钮:把统计摘要(指标/数值逐行)导出为
`labvault-analysis-<id>-summary.csv`,**带 BOM**,Excel/Numbers 双击直开不乱码。

### 2. 统计页「导出结果 JSON」

统计分析中心跑出结果后新增「导出结果 JSON」按钮(与「保存到数据集」并排):
`labvault-result-<method>-<时间戳>.json`,含 method/参数/结果/数据集上下文/
已保存的 analysis_id —— 保存前也能导出,随时可复现。

## 验证

- CSV 实测:573B, text/csv;charset=utf-8,含 BOM ✓
- 结果 JSON 实测:1266B, application/json ✓
