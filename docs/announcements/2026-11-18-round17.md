# LabVault 更新公告 2026-11-18(第 17 轮 · 统计↔数据表双向深链)

## 新增

### 1. 统计页来源 Chip 可点击回跳

统计页的「数据来源:…」Chip 现在可点击 → 携带
`?dataset=&project=` 跳转数据表格页,网格自动载入该数据集。

### 2. 数据表格支持 URL 深链

`/data?dataset=<id>&project=<pid>` 直达指定数据集(URL 优先于"自动选第一个",
与图表页同规则)。至此三个页面互相跳转全部带上数据集上下文:

```
数据表格 ⇄ 统计分析 ⇄ 图表构建   (任何跳转都保留 ?dataset=&project=)
```
