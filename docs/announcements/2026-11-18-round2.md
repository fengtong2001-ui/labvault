# LabVault 更新公告 2026-11-18(第 2 轮 · 结果工作表落库)

> 承接第 1 轮(round1)的 GraphPad 式整合,本轮把**分析结果与图表持久化**打通:
> 统计检验和图表不再是"跑完即逝",而是像 Prism 的 Results/Graphs 工作表一样
> 挂在数据集下,可随时回看。

## 新增

### 1. 结果落库 API(backend)

- `POST /api/analyses` — 保存统计结果 `{analysis_type, params, result, dataset_id, project_id}`
- `GET  /api/analyses?dataset_id=|project_id=` — 按数据集/项目列出
- `POST /api/charts` — 保存图表 `{chart_type, plotly_json, title, dataset_id, project_id, analysis_id}`
- `GET  /api/charts?dataset_id=|project_id=` — 按数据集/项目列出
- 复用 db.py 已有的 `save_analysis/save_chart`(swarm 初版就埋好的层,本轮接上 server 路由)

### 2. 「保存到数据集」按钮(frontend)

- **统计分析中心**:跑出结果后可一键保存(记录 method/参数/结果/数据集上下文),
  按钮旁即时反馈「已保存到数据集 ✓」
- **图表构建器**:生成后可一键保存整份 Plotly JSON,同样即时反馈
- `utils/api.js` 新增 `analysesApi` 与 `chartsApi.save/list`
