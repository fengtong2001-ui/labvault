# LabVault 更新公告 2026-11-18(第 3 轮 · 特殊图型两段式 + 工作簿面板)

## 新增

### 1. IC50 / Kaplan-Meier / ROC 从数据集自动推导(datasetStats 扩展)

这三类图型在 Prism 里都是"数据表 → 分析 → 曲线"两段式。现在支持:

- **IC50/EC50**:识别「浓度/concentration/剂量」列 + 「抑制率/response/活性」列
  → 先走 `POST /api/stats/ic50`(4PL 拟合出 IC50)→ 再用拟合结果出剂量-效应曲线
- **Kaplan-Meier**:识别「时间/time」+「事件/event/status」列(可选分组列)
  → `POST /api/stats/survival`(KM + Log-rank)→ 生存曲线
- **ROC**:识别「标签/label/诊断」+ 「评分/score」列
  → `POST /api/stats/roc`(AUC + 约登指数)→ ROC 曲线

实现:`chartParamsFromDataset` 对特殊图型返回 `{__statEndpoint, payload}`,
ChartBuilder 统一调度"统计 API → 图表 API"两段管线,结果落库保存。

**实测**:IC50 语义数据集(浓度 nM / 抑制率 %)→ 图表页选 IC50/EC50 →
拟合曲线 + 6 个原始数据点,对数浓度轴(1 / 100 / 10k)正确渲染。

### 2. 数据表格页新增「工作簿」面板

选中数据集后,页面底部显示该数据集下**已保存的图表与分析结果**
(Prism 式 Results/Graphs 工作表):图表 3 · 分析结果 2,逐条列出标题/类型/
时间,分析结果直接展示结论行(如"两组差异显著(p<0.0001)")。
