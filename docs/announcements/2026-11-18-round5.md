# LabVault 更新公告 2026-11-18(第 5 轮 · 双向关联 + 主题持久化)

## 新增

### 1. 工作簿分析条目「从该分析出图」(双向关联完成)

工作簿面板的每条分析结果现在带「从该分析出图」按钮 → 跳转图表页并携带
`?dataset=&project=&analysis=<id>`,自动以该数据集真实数据生成图表,
保存时自动挂钩 `analysis_id`。

至此关联闭环双向可用:

```
数据表 → 统计分析 → 保存分析 ─┬─→ 生成关联图表 → 保存图表(analysis_id 落库)
                              └─ 工作簿任意历史分析 → 从该分析出图 → 同上
```

**实测**:工作簿 ttest 条目 → 从该分析出图 → URL `?...analysis=3` →
来源标签「关联分析 #3」→ 真实柱状图渲染 → 保存落库
`{dataset_id: 2, analysis_id: 3}` ✓
