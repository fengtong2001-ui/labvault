# LabVault 更新公告 2026-11-18(第 7 轮 · 工作簿条目管理:删除/重新生成)

## 新增

### 1. 工作簿条目删除

- 图表与分析条目均有删除按钮(带确认弹窗,防误删)
- backend 新增 `DELETE /api/analyses/<id>` 与 `DELETE /api/charts/<id>`
  (db 层 `delete_analysis/delete_chart`)
- 删除后工作簿即时刷新,Snackbar 反馈

### 2. 图表条目「重新生成」

- 图表条目新增刷新按钮 → 携带数据集与图型跳转
  `/charts?dataset=<id>&project=<pid>&type=<chart_type>`
- ChartBuilder 支持 `?type=` 直接进入指定图型并自动生成
  (数据来源标签诚实标注:真实数据集/演示数据)

## 验证

- curl:创建一次性 analysis/chart → DELETE → 列表无残留
- UI:删除图表条目(工作簿计数 4→3 + Snackbar「图表已删除」);
  重新生成按钮 → `/charts?...&type=bar` → 自动生成数据集真实图
