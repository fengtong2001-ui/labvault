# LabVault 更新公告 2026-11-18(第 8 轮 · 数据集保存体验)

## 新增

### 1. 未保存改动跟踪

- 网格内容/列名/数据集名称与最近一次「保存或载入」的快照实时比对
- 有未保存更改时:名称栏提示「(有未保存更改)」+ 警示 Chip「● 未保存更改」
  + 保存按钮变为「保存表格 *」并切换强调色
- `beforeunload` 守卫:带未保存改动刷新/关闭页面时浏览器弹出确认

### 2. 保存自动命名

数据集名仍为默认「未命名数据集」或为空时,保存自动按
`项目名-数据集-日期` 生成(如 `Test Project-数据集-2026-11-18`),并回填输入框。

## 验证

- 载入数据集 → 无未保存标记;编辑单元格 → 「未保存更改」+「保存表格 *」;
  保存 → 标记消失 + 「数据集已更新保存」
- 清空名称保存 → 自动命名回填并落库 ✓
