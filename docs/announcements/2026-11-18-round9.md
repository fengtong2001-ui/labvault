### 数据表格页内嵌快速统计(Prism 式即时反馈)

点任意列头的 📊 图标(数值列),操作栏立即显示该列:

```
快速统计:反应值   n=15   mean=5.800 ± 0.673   [4.8, 6.8]
```

- n / mean / SD / min / max,跟随网格实时重算(编辑即刷新)
- 非数值列显示「无数值」;空串/缺失自动排除
- 再点一次图标或点 Chip 的 × 关闭

**实测**:反应值列 n=15 mean=5.800±0.673 [4.8, 6.8](一行编辑产生的
'5.15.7' 非法值被 NaN 过滤正确排除——快速统计还顺手当起了数据质检员)。

## 工程说明(重要)

本轮排查发现 **CRA 5 的 react-scripts dev server 在 Node 24 下会"编译成功"
但持续服务旧内存包**——此前浏览器里跑的一直是旧代码,新改动迟迟不生效的
根源在此(与本轮功能无关,纯环境问题)。

处置:日常运行切换为 **生产构建 + SPA 静态服务器**:

```
npm run build
python3 scripts/serve_spa.py     # PORT 环境变量可覆盖,默认 3210
```

`scripts/serve_spa.py` 为零依赖 SPA 服务器(静态资源 + 前端路由回退),
已入库。npm start(react-scripts)保留但不再作为运行方式。
